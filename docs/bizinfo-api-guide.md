# 기업마당(bizinfo.go.kr) API 키 발급 가이드

## 📌 기업마당이란?

기업마당은 **중소벤처기업부**가 운영하는 정부 지원사업 통합 포털입니다.
NIPA, NIA, 행안부, 부산시 등 **전국 공공기관의 지원사업 공고**가 모두 여기에 모입니다.

API 키를 한 번 발급받으면, 별도 크롤링 없이도 다양한 기관의 공고를 한 번에 검색할 수 있습니다.

---

## 🔑 API 키 발급 절차 (5분 소요)

### Step 1. 기업마당 회원가입
1. [기업마당](https://www.bizinfo.go.kr) 접속
2. 우측 상단 **회원가입** 클릭
3. 일반 회원으로 가입 (개인/기업 무관)

### Step 2. 정책정보 개방 메뉴 접속
1. 로그인 후 상단 메뉴에서 **[정책정보 > 정책정보 개방]** 클릭
2. 또는 직접 URL 접속: `https://www.bizinfo.go.kr/web/lay1/bbs/S1T122C128/AS/74/view.do`

### Step 3. API 인증키 신청
1. **[인증키 신청]** 버튼 클릭
2. 활용 목적 입력 (예: "AI 관련 지원사업 공고 모니터링")
3. **신청 완료** → 즉시 또는 1~2시간 내 발급

### Step 4. 인증키 확인
1. 정책정보 개방 메뉴 > **[나의 인증키]** 탭
2. 발급된 **인증키(crtfcKey)** 복사

### Step 5. 환경변수 설정
```bash
# /Users/gyoungmin.lee/Desktop/나라장터봇/app/.env.local 파일에 추가
BIZINFO_API_KEY=여기에_발급받은_인증키_붙여넣기
```

## 🧪 발급 후 테스트

터미널에서 아래 명령어로 바로 테스트할 수 있습니다:

```bash
curl -s "https://www.bizinfo.go.kr/uss/rss/bizinfoApi.do?crtfcKey=발급받은키&dataType=json&pageUnit=5&srchKeyword=AI" | python3 -m json.tool | head -50
```

정상 응답이 오면 성공입니다!

## ❓ FAQ

**Q. 무료인가요?**
A. 네, 완전 무료입니다. 일일 호출 제한도 넉넉합니다 (보통 10,000건/일).

**Q. 승인이 안 돼요**
A. 보통 즉시 발급되지만, 최대 1~2시간 걸릴 수 있습니다. 영업일 기준.

**Q. 공공데이터포털(data.go.kr)에서도 되나요?**
A. 네, data.go.kr에서 "기업마당 지원사업정보"를 검색해도 동일한 API를 신청할 수 있습니다.
